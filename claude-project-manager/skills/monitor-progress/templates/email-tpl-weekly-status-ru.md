# Email-шаблон E7 — Рассылка еженедельного статуса

**Уровень автономности:** 1 (автономно — отправляется без подтверждения PM)
**Используется в:** monitor-progress, режим weekly-status (Scheduled Task Р1)

---

## Получатели

**Кому:** {STAKEHOLDERS — из comm-plan.md, список рассылки еженедельного статуса}
**Копия:** {PM_NAME} — Руководитель проекта
**Тема:** [{PROJECT_NAME}] Еженедельный статус — Спринт {SPRINT_NUMBER}, Неделя {WEEK_NUMBER}

---

## Тело письма

Добрый день, {RECIPIENT_NAME},

Еженедельный отчёт о статусе проекта **{PROJECT_NAME}**.

**Общий статус: {ЗЕЛЁНЫЙ — В плане / ЖЁЛТЫЙ — Под угрозой / КРАСНЫЙ — Критические проблемы}**

**Прогресс спринта {SPRINT_NUMBER}:**
- Выполнено: {COMPLETION_PERCENT}% ({TASKS_COMPLETED}/{TASKS_PLANNED} задач)
- Скорость: {VELOCITY} story points
- Статус сроков: {В ПЛАНЕ / НЕЗНАЧИТЕЛЬНЫЕ ЗАДЕРЖКИ / ЗАДЕРЖКА — {MAX_DELAY_DAYS} дн.}
- Статус бюджета: {В ПЛАНЕ / НЕЗНАЧИТ. ПРЕВЫШЕНИЕ / ПРЕВЫШЕНИЕ — {DEVIATION_PERCENT}%}

**Достижения этой недели:**
- {ACHIEVEMENT_1}
- {ACHIEVEMENT_2}

**Ключевые проблемы / Блокеры:**
{KEY_ISSUES или «Критических проблем на этой неделе нет.»}
- {ISSUE_DESCRIPTION} — Владелец: {OWNER}

**Фокус следующего спринта:**
- {NEXT_FOCUS_1}
- {NEXT_FOCUS_2}

**Следующая веха:** {MILESTONE_NAME} — {MILESTONE_DATE}

Полный еженедельный отчёт: `reports/weekly-status-{DATE}.md`

С уважением,
AI Project Manager | {PROJECT_NAME}

*Этот отчёт формируется автоматически каждый понедельник в 9:00.*
*Для изменения частоты рассылки обратитесь к {PM_EMAIL}.*

---

## Инструкции для агента

- Заполни все плейсхолдеры `{}` из weekly-status-{date}.md
- Получатели: по списку еженедельной рассылки в comm-plan.md (или stakeholder-map.md при его отсутствии)
- PM всегда в «Копия»
- Уровень 1 — отправить автономно через send-email БЕЗ подтверждения PM
- Вложение: конвертировать weekly-status-{date}.md → .docx, прикрепить к письму
- Записать в logs/log.md: «{DATE}: email E7 отправлен — еженедельный статус Спринт {SPRINT_NUMBER}»
