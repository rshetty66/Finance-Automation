# Инструкция: письмо с опросником по урокам

## Параметры отправки

| Параметр | Значение |
|----------|----------|
| Получатели | `{{recipient_emails}}` (список через запятую) |
| Копия (CC) | `{{pm_email}}` |
| Тема | Опросник: извлечённые уроки — проект {{project_name}} |
| Вложение | `questionnaire-lessons.md` |
| Уровень автономности | 2 — агент отправляет, PM автоматически в копии |

## Текст письма

---

Тема: Опросник: извлечённые уроки — проект {{project_name}}

Команда,

Проект **{{project_name}}** завершён. Прошу уделить 15–20 минут и ответить на вопросы в прикреплённом опроснике.

Ваши ответы помогут нам сделать следующие проекты лучше — улучшить процессы, коммуникации и технические подходы.

Прошу прислать ответы до **{{deadline}}**. Формат свободный — отвечать можно прямо в файле или ответным письмом.

Спасибо за участие в проекте.

{{pm_name}}

---

## Инструкции для агента

1. Получить список получателей — из CLAUDE.md управляемого проекта (раздел команды).
2. Убедиться, что `questionnaire-lessons.md` создан.
3. Подставить в текст письма: `{{project_name}}`, `{{pm_name}}`, `{{deadline}}`, `{{recipient_emails}}`.
4. Добавить `{{pm_email}}` в CC.
5. Отправить через Gmail MCP (уровень 2 — подтверждение не требуется, но PM в копии).
6. Зафиксировать в `logs/log.md`: дата отправки, список получателей.
