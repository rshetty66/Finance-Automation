# Инструкция: письмо с опросником для заказчика

## Параметры отправки

| Параметр | Значение |
|----------|----------|
| Получатель | `{{recipient_email}}` |
| Копия (CC) | `{{pm_email}}` |
| Тема | Опросник по проекту {{project_name}} — прошу заполнить |
| Вложение | `questionnaire-client.docx` |
| Уровень автономности | 3 — черновик показать человеку, отправлять только после подтверждения |

## Текст письма

---

Тема: Опросник по проекту {{project_name}} — прошу заполнить

Здравствуйте, {{recipient_name}}!

Направляю опросник для сбора требований по проекту **{{project_name}}**.

Ваши ответы помогут нам точно зафиксировать цели, ожидания и ограничения, и лягут в основу устава проекта. Это займёт около 15–20 минут.

Прошу заполнить опросник (вложен к письму) и направить ответы в ответном письме или в удобном формате до **{{deadline}}**.

По любым вопросам обращайтесь напрямую.

С уважением,
{{pm_name}}
{{pm_title}}

---

## Инструкции для агента

1. Прочитать `questionnaire-client.md` — убедиться, что файл создан и метаданные заполнены.
2. Конвертировать `questionnaire-client.md` → `questionnaire-client.docx` (через send-email).
3. Подставить в текст письма значения: `{{recipient_name}}`, `{{project_name}}`, `{{pm_name}}`, `{{pm_title}}`, `{{deadline}}`.
4. Показать черновик письма человеку.
5. Дождаться подтверждения.
6. После подтверждения — отправить через Gmail MCP.
7. Зафиксировать в `logs/log.md`: дата отправки, получатель.
