# change-impact-{id}.xlsx — Схема артефакта (RU)

Файл определяет структуру, разметку столбцов, формулы и примеры данных
для артефакта `change-impact-{id}.xlsx`, создаваемого скиллом `generate-change-impact`.

---

## Метаданные файла

| Поле | Значение |
|------|---------|
| Имя файла | `change-impact-{id}.xlsx` (пример: `change-impact-CR-001.xlsx`) |
| Путь сохранения | `{project}/04-development/` |
| Листы | 2 — Сводка (Summary), Детали влияния (Impact Detail) |
| Версия | 1.0 |

---

## Лист 1 — Сводка (Summary)

### Блок заголовка (строки 1–5)

| Ячейка | Содержимое |
|--------|-----------|
| A1 | «Проект:» |
| B1 | `{название_проекта}` — из project-charter.md или от PM |
| A2 | «PM:» |
| B2 | `{имя_pm}` |
| A3 | «Фаза:» |
| B3 | «4 — Разработка» |
| A4 | «Дата оценки:» |
| B4 | `{ГГГГ-ММ-ДД}` |
| A5 | «Версия:» |
| B5 | «1.0» |

---

### Блок запроса на изменение (строки 8–15)

| Поле | Содержимое |
|------|-----------|
| ID запроса | `{CR-001}` |
| Название | `{краткое_название_изменения}` |
| Категория | `{scope / budget / timeline / resource}` |
| Вторичные категории | `{если применимо, иначе «—»}` |
| Инициатор | `{имя_инициатора_или_роль}` |
| Дата запроса | `{ГГГГ-ММ-ДД}` |
| Описание | `{1–3 предложения: что именно меняется}` |
| Обоснование | `{1–2 предложения: почему изменение необходимо}` |

> **Инструкция для агента:** заполните все поля на основе данных от PM из Шага 2.
> Если данные не предоставлены — оставьте `«не указано»`.
> Категорию определите автоматически на основе описания; вторичные категории указывайте
> только если изменение явно затрагивает несколько измерений.

---

### Блок оценки влияния (строки 18–26)

| Измерение | Показатель | Значение |
|-----------|-----------|---------|
| Сроки | Сдвиг финального дедлайна | `{+X рабочих дней / «не затрагивает»}` |
| Сроки | Затронутые задачи | `{N задач / «не затрагивает»}` |
| Сроки | Критический путь | `{«сдвигает» / «не сдвигает»}` |
| Бюджет | Дельта (абсолютная) | `{+X ₽/$ / «0» / «требует уточнения»}` |
| Бюджет | Дельта (%) | `{+X% / «0%» / «требует уточнения»}` |
| Ресурсы | Требуются изменения | `{«да» / «нет»}` |
| Ресурсы | Описание | `{если «да» — что именно / «—»}` |
| **Уровень влияния** | | `{Low / Medium / High}` |

**Цветовое кодирование уровня влияния:**
- Low: зелёная заливка (#C6EFCE)
- Medium: жёлтая заливка (#FFEB9C)
- High: красная заливка (#FFC7CE)

> **Инструкция для агента:** уровень влияния определяется по матрице из skill-spec-ru.md
> (Шаг 4.4). Строку «Уровень влияния» выделить жирным + заливка по цвету выше.
> Источник данных указать в Листе 2 (Impact Detail).

---

### Блок рекомендации агента (строки 29–31)

| Поле | Содержимое |
|------|-----------|
| Рекомендация агента | `{1–2 предложения: краткий вывод об уровне влияния и ключевых рисках}` |
| Ключевой риск | `{главный риск при принятии изменения, 1 предложение}` |
| Ключевой риск при отказе | `{риск при отклонении изменения, 1 предложение или «—»}` |

> **Инструкция для агента:** напишите объективную оценку без рекомендации «одобрить/отклонить».
> Пример: «Изменение добавляет 2 новых модуля, сдвигает дедлайн спринта 3 на 8 рабочих
> дней и увеличивает бюджет на 12%. Основной риск — перегрузка команды backend.»
> НЕ писать «рекомендую одобрить/отклонить» — это решение PM.

---

|------|-----------|

| Дата решения | _(PM заполняет)_ |

### Блок допущений (строки 42–48)

| # | Допущение |
|---|----------|
| 1 | Оценка влияния основана на данных project-plan.md и project-budget.xlsx на дату оценки |
| 2 | Если файлы проекта не загружены — оценка базируется на описании PM и является предварительной |
| 3 | Уровень влияния: Low (сдвиг ≤ 5 дней, дельта бюджета ≤ 5%), Medium (6–15 дней / 6–15%), High (>15 дней / >15%) |
| 4 | Сдвиг сроков указан в рабочих днях (5 дней в неделю) |
| 5 | Финансовые данные в валюте проекта |
| 6 | `{дополнительные_примечания_агента}` |

### Блок заголовка (строки 1–3)

| Ячейка | Содержимое |
|--------|-----------|
| A1 | «Проект:» |
| B1 | `{название_проекта}` |
| A2 | «CR ID:» |

| A3 | «Источник данных:» |

---

### Блок 1 — Влияние на сроки (строки 6 и далее)

Таблица затронутых задач/вех:

| Задача / Веха | Текущий срок | Новый срок | Сдвиг (рабочих дней) | Критический путь | Комментарий |
|--------------|-------------|-----------|---------------------|-----------------|-----------|
| `{название_задачи}` | `{ГГГГ-ММ-ДД}` | `{ГГГГ-ММ-ДД}` | `{+N}` | `{да / нет}` | `{обоснование}` |
| ... | | | | | |
| **Итого: сдвиг финального дедлайна** | | | `=СУММ(столбец_сдвигов_по_кр_пути)` | | |

> **Инструкция для агента:** добавляйте строки для каждой затронутой задачи из project-plan.md.
> Если файл не загружен — укажите задачи на основе описания изменения от PM с пометкой «оценка».
> Если изменение не затрагивает сроки — напишите «Изменение не затрагивает временной план».

**Форматирование:**
- Задачи на критическом пути: жирный
- Строка итого: жёлтая заливка (#FFF2CC), жирный
- Положительный сдвиг (задержка): красный цвет текста
- Нулевой сдвиг: стандартный цвет

---

### Блок 2 — Влияние на бюджет (после таблицы сроков, через 3 строки)

Таблица затронутых статей бюджета:

| Статья бюджета | Утверждённая сумма | Новая сумма | Дельта | Дельта (%) | Комментарий |
|---------------|-------------------|------------|--------|-----------|-----------|
| `{название_статьи}` | `{сумма}` | `{новая_сумма}` | `=Новая-Утверждённая` | `=Дельта/Утверждённая*100` | `{обоснование}` |
| ... | | | | | |
| **Итого** | `=СУММ(утверждённые)` | `=СУММ(новые)` | `=СУММ(дельты)` | `=Итого_дельта/Итого_утв*100` | |

> **Инструкция для агента:** добавляйте строки для затронутых статей бюджета из project-budget.xlsx.
> Если файл не загружен — укажите статьи на основе описания с пометкой «оценка» и значение «требует уточнения».
> Если изменение не затрагивает бюджет — напишите «Изменение не затрагивает бюджет».

**Форматирование:**
- Сумма денег: числовой формат с разделителем тысяч, 2 знака после запятой
- Строка итого: жёлтая заливка (#FFF2CC), жирный
- Положительная дельта (перерасход): красный цвет текста

---

### Блок 3 — Влияние на ресурсы (после таблицы бюджета, через 3 строки)

| Ресурс / Роль | Текущая загрузка | Требуемая загрузка | Дельта | Комментарий |
|--------------|----------------|-------------------|--------|-----------|
| `{роль_или_имя}` | `{X%_или_X_дней}` | `{Y%_или_Y_дней}` | `{+Z}` | `{обоснование}` |

> **Инструкция для агента:** заполняйте только если изменение требует ресурсных изменений.
> Если ресурсы не затронуты — напишите «Изменение не требует ресурсных изменений».

---

### Блок 4 — Зависимости и смежные эффекты (после таблицы ресурсов, через 3 строки)

| Затронутый элемент | Тип | Описание эффекта |
|-------------------|-----|-----------------|
| `{веха / риск / статья_плана_коммуникаций}` | `{milestone / risk / comm-plan / other}` | `{1–2 предложения}` |

> **Инструкция для агента:** укажите смежные эффекты — вехи, которые сдвигаются, риски,
> которые обостряются, изменения в плане коммуникаций. Если явных смежных эффектов нет —
> напишите «Смежных эффектов не выявлено».

## Правила оформления

| Элемент | Стиль |
|---------|-------|
| Блоки заголовков | Жирный, серая заливка (#D9D9D9) |
| Строки данных | Чередование белый / светло-голубой (#EBF3FB) |
| Строки итого | Жёлтая заливка (#FFF2CC), жирный |
| Уровень влияния Low | Зелёная заливка (#C6EFCE) |
| Уровень влияния Medium | Жёлтая заливка (#FFEB9C) |
| Уровень влияния High | Красная заливка (#FFC7CE) |
| Положительная дельта (задержка/перерасход) | Красный цвет текста (#9C0006) |
| Критический путь | Жирный |
| Заголовки блоков | Жирный, заглавные буквы |
| Ширина столбцов (Лист 1) | Поле: 28; Значение: 48 |
| Ширина столбцов (Лист 2, сроки) | Задача: 30; Даты: 14; Сдвиг: 10; Кр. путь: 12; Комментарий: 40 |
| Ширина столбцов (Лист 2, бюджет) | Статья: 30; Суммы: 16; Дельта: 12; %: 10; Комментарий: 40 |
| Закреплённые строки | Строка 1 на каждом листе |
