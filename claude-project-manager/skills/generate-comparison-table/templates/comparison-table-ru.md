### Сводная таблица оценок (строки 17–27)

Разметка столбцов: `Критерий | Вес (%) | [Прототип A] | [Прототип B] | [Прототип C] | [Прототип D]`

> Инструкция для агента: используйте реальные названия прототипов из описаний PM. Добавляйте/
> убирайте столбцы прототипов по необходимости (2–4 столбца). Лишние столбцы удаляйте полностью.

| Критерий | Вес (%) | Прототип A | Прототип B | Прототип C |
|---------|---------|------------|------------|------------|
| Техническая реализуемость | 25% | {балл_1A} | {балл_1B} | {балл_1C} |
| Качество UX | 25% | {балл_2A} | {балл_2B} | {балл_2C} |
| Стоимость разработки | 20% | {балл_3A} | {балл_3B} | {балл_3C} |
| Срок реализации | 15% | {балл_4A} | {балл_4B} | {балл_4C} |
| Уровень рисков | 15% | {балл_5A} | {балл_5B} | {балл_5C} |
| **Взвешенный итог** | — | `=СУММПРОИЗВ(веса; баллы_A)` | `=СУММПРОИЗВ(веса; баллы_B)` | `=СУММПРОИЗВ(веса; баллы_C)` |
| **Место** | — | `=РАНГ(ВИ_A; все_ВИ)` | `=РАНГ(ВИ_B; все_ВИ)` | `=РАНГ(ВИ_C; все_ВИ)` |

**Формула взвешенного итога (ручной расчёт):**
`Взвешенный итог = Σ (Вес_i% × Балл_i) / 100`
Диапазон результата: 1.00 – 5.00. Выше = лучше.

**Форматирование ячеек:**
- Ячейки баллов (1–5): число, 1 знак после запятой
- Взвешенный итог: число, 2 знака после запятой, **жирный**
- Место: целое, **жирный**
- Строка места «1»: зелёная заливка (#C6EFCE)

### Справочник по шкале (ниже матрицы)

| Балл | Значение |
|------|---------|
| 5 | Отлично / очень просто / минимальная стоимость / самый быстрый / минимальный риск |
| 4 | Хорошо / управляемо |
| 3 | Нейтрально / среднее / неопределённо |
| 2 | Сложно / выше среднего по стоимости или риску |
| 1 | Очень сложно / дорого / высокий риск / медленнее всех |

> Примечание: все критерии используют соглашение «выше = лучше». Для стоимости, рисков и
> сложности балл 5 означает «низкая стоимость», «низкий риск», «легко реализовать» соответственно.
