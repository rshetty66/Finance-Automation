# Справочник: Аналоги для оценки IT-проектов

Используется скиллом `generate-estimate` как отправная точка для построения оценки по аналогии.
Все значения — рыночные диапазоны на основе экспертных знаний агента. PM корректирует под конкретный контекст.

## Правила применения аналогов

1. Определить тип проекта → взять строку из первой таблицы.
2. Определить состав команды → взять ставки из второй таблицы.
3. Рассчитать командный бюджет: роль × FTE × недели × ставка.
4. Добавить инфраструктурные расходы пропорционально длительности.
5. GTM-бюджет добавлять только если фаза 5 в скоупе.
6. Если данные из проектных файлов противоречат аналогам — использовать данные проекта, аналоги как нижнюю границу.
