# Project Manager — плагин для Claude Cowork

[English version](README.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform: Claude Cowork](https://img.shields.io/badge/Platform-Claude%20Cowork-6B4FBB.svg)](https://claude.ai)

Плагин для полного цикла управления IT-проектами в Claude Cowork. Покрывает все 32 задачи менеджера проекта на 6 фазах — от инициации до закрытия. Методологическая основа: гибрид PMBoK 8 + Agile. Двуязычный: английский и русский, определяется автоматически.

## Быстрый запуск

1. Установите плагин в Claude Cowork
2. Выберите или создайте папку проекта
3. Запустите `/init-project [название-проекта]`
4. Авторизуйте MCP-коннекторы при запросе (Jira, Gmail, Calendar)
5. Подтвердите разрешения для регламентных задач при первом запуске

Плагин инициализирует структуру папок проекта и автоматически запускает фазу 1.

## Что делает плагин

- Генерирует 34 типа проектных документов: уставы, планы, бюджеты, реестры рисков, протоколы, чек-листы
- Отслеживает прогресс и автоматически выявляет отклонения по срокам и бюджету
- Координирует встречи и распределение задач через интеграции
- Отправляет email-уведомления с настраиваемым уровнем автономности (авто / копия PM / подтверждение)
- Запускает регламентные проверки: ежедневные отклонения, еженедельный статус, обновление реестра рисков
- Автоматически определяет язык запроса — отвечает на русском или английском

## Команды (8)

| Команда | Назначение |
|---------|------------|
| `/init-project` | Инициализация проекта: папки, статус, регламентные задачи, запуск фазы 1 |
| `/status` | Текущий статус проекта и доступные следующие шаги |
| `/next-step` | Рекомендация следующего действия по карте зависимостей |
| `/sprint-report` | Еженедельный отчёт о прогрессе спринта |
| `/deviation-check` | Проверка отклонений по срокам и бюджету |

## MCP-интеграции

| Сервер | Назначение |
|--------|------------|
| Atlassian (Jira) | Управление задачами: создание, чтение, обновление, поиск |
| Gmail | Email: поиск, чтение, создание черновиков |
| Google Calendar | События: создание, чтение, поиск |

Все интеграции опциональны — плагин работает без них, генерируя файловые артефакты с инструкциями для ручного выполнения.

## Структура проекта

Плагин создаёт и ведёт следующую структуру папок:

```
{название-проекта}/
├── CLAUDE.md                  # Инструкции агента (автогенерируются)
├── project-state.md           # Реестр статусов артефактов
├── 01-initiation/             # Артефакты фазы 1
├── 02-planning/               # Артефакты фазы 2
├── 03-execution/              # Артефакты фаз 3–5
├── 04-closure/                # Артефакты фазы 6
├── meetings/                  # Повестки и протоколы
├── reports/                   # Регламентные и периодические отчёты
├── input/                     # Данные пользователя (только чтение)
├── logs/log.md                # Лог действий агента
└── archive/                   # Создаётся при закрытии проекта
```

## Регламентные задачи

| Задача | Расписание | Фазы | Назначение |
|--------|------------|------|------------|
| `weekly-status` | Пн 9:00 | 3–5 | Еженедельный отчёт о прогрессе |
| `daily-deviation` | Пн–Пт 9:00 | 3–5 | Проверка отклонений по срокам и бюджету |
| `risk-update` | Пн 9:00 (по спринтам) | 2–5 | Обновление реестра рисков |
| `sync-streams` | Пн 9:00 | 5 | Синхронизация потоков работ |
| `executor-reminders` | Пн–Пт 10:00 | 3–5 | Напоминания по просроченным задачам |

Все регламентные задачи также доступны как слэш-команды для ручного запуска.

## Кастомизация

Плагин использует синтаксис `~~placeholder` для внешних инструментов. Подробнее о замене интеграций (например, Linear вместо Jira, Outlook вместо Gmail) — в файле `CONNECTORS.md`.
