# Руководство по установке — плагин Project Manager для Claude Cowork

[English version](INSTALL-COWORK.md)

Это руководство проведёт вас через установку плагина Project Manager в Claude Cowork и подготовку к первому проекту. Весь процесс занимает около 5 минут.

---

## Требования

Перед началом убедитесь, что у вас есть:

- **Десктопное приложение Claude** с включённым режимом Cowork (macOS или Windows)
- **Подписка Claude Pro или Max** — обязательна для работы в Cowork
- **Папка на компьютере** для хранения файлов проектов (можно создать в процессе установки)
- **MCP-интеграции** (опционально): аккаунты Jira, Gmail и Google Calendar — нужны только если вы хотите автоматическую синхронизацию с этими сервисами

> Плагин полностью работает без Jira, Gmail и Calendar. Без них он создаёт файловые документы с инструкциями для ручных действий вместо автоматической синхронизации.

---

## Шаг 1 — Скачайте файл плагина

1. Откройте GitHub-репозиторий: [project-manager-cowork-plugin](https://github.com/your-repo-link)
2. В правой части страницы нажмите на раздел **Releases**
3. Найдите последний релиз (например, `v0.1.2`)
4. В разделе **Assets** нажмите на `project-manager-X.X.X.plugin` для скачивания
5. Сохраните файл в удобное место (например, в папку Загрузки)

Плагин — это единственный файл `.plugin`. Распаковывать архив или запускать установщик не нужно.

---

## Шаг 2 — Установите плагин в Claude Cowork

1. Откройте десктопное приложение **Claude** на своём компьютере
2. Переключитесь в режим **Cowork** (кнопка в верхней навигационной панели по центру)
3. В интерфейсе Cowork нажмите иконку **+**
4. В меню выберите **Plugins**
5. Нажмите **Add Plugin**
6. Выберите **Install from file** и найдите файл `.plugin`, скачанный в Шаге 1
7. Cowork проверит плагин (несколько секунд)
8. Нажмите **Install** для подтверждения

После установки **Project Manager** появится в списке плагинов.

> **Если появилась ошибка «Plugin validation failed»:** скачайте файл `.plugin` с GitHub повторно. Возможно, файл скачался не полностью.

---

## Шаг 3 — Подключите рабочую папку

Плагин создаёт файлы проектов и управляет ими напрямую на вашем компьютере. Нужно указать ему папку, где будут храниться проекты.

1. В интерфейсе Cowork нажмите **Work in a folder** (кнопка в левом нижнем углу)
2. Выберите существующую папку или создайте новую (рекомендуется: `~/Documents/projects/`)
3. Нажмите **Allow**, чтобы предоставить Cowork доступ к папке

> **Совет:** используйте одну общую папку для всех проектов — плагин создаст отдельную подпапку для каждого проекта внутри неё. Например: `~/Documents/projects/запуск-сайта/`, `~/Documents/projects/мобильное-приложение/`.

---

## Шаг 4 — Подключите MCP-интеграции (опционально)

MCP-интеграции позволяют плагину автоматически читать задачи из Jira, отправлять письма через Gmail и создавать события в Google Calendar. Этот шаг опциональный — пропустите его, если предпочитаете работать только с файлами.

**Как подключить интеграцию:**

1. В боковой панели Cowork нажмите **Connectors**
2. Найдите нужный сервис: **Atlassian (Jira)**, **Gmail** или **Google Calendar**
3. Нажмите **Connect**
4. Вы будете перенаправлены на страницу входа сервиса (стандартная OAuth-авторизация — пароли плагину не передаются)
5. Войдите в аккаунт и предоставьте запрошенные разрешения
6. После авторизации статус коннектора сменится на **Connected**

Повторите для каждого сервиса, который хотите подключить.

> Вы можете подключать и отключать интеграции в любой момент — это не повлияет на файлы проектов и не потребует переустановки плагина.

---

## Шаг 5 — Выполните первую команду

Откройте новую сессию Cowork и введите:

```
/init-project my-first-project
```

Замените `my-first-project` на короткое название вашего проекта (используйте дефисы вместо пробелов, рекомендуется латиница, например `website-relaunch` или `mobile-app-v2`).

Плагин:
- Создаст структуру папок для проекта в рабочей директории
- Сгенерирует файл `CLAUDE.md` с инструкциями для агента
- Создаст файл `project-state.md` для отслеживания артефактов
- Запустит Фазу 1 (Инициация) и запросит первые данные

---

## Шаг 6 — Проверьте установку

Если в ответ на `/init-project` появилось подтверждающее сообщение со списком созданных папок и запросом данных о проекте — установка завершена и плагин работает корректно.

Для проверки статуса плагина в любой момент введите:

```
/status
```

Будет показана текущая фаза проекта, созданные артефакты и рекомендуемые следующие шаги.

---

## Устранение неполадок

**Плагин не появился в списке после установки**
→ Перезапустите десктопное приложение Claude и попробуйте снова.

**Ошибка «Plugin validation failed» при установке**
→ Скачайте файл `.plugin` с GitHub повторно. Файл мог скачаться не полностью.

**`/init-project` не отвечает или показывает ошибку**
→ Убедитесь, что вы подключили рабочую папку на Шаге 3 (кнопка **Work in a folder** в левом нижнем углу). Без папки плагин не может создавать файлы.

**MCP-коннектор показывает «Authentication failed»**
→ Отключите интеграцию и подключите снова. Убедитесь, что при авторизации вы вошли в правильный аккаунт в браузере.

**Файлы создаются не в той папке**
→ Нажмите **Work in a folder** снова и выберите нужную папку заново.

**Вышла новая версия плагина — нужно ли переустанавливать?**
→ Да. Нажмите иконку **+** → **Plugins**, найдите Project Manager, удалите его, затем установите новый файл `.plugin` по инструкции из Шага 2.
